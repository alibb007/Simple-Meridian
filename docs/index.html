Run the full version on your computer

This page only replays results. The full app fits Meridian on your own data, runs budget plans and GeoX (Lift test)NEW experiments, and keeps your data on your machine. It runs in Docker Desktop on a Mac or a Windows PC. Tested so far on Apple silicon; the Intel/Windows build passed a full model fit under emulation.

1. Get the code

git clone https://github.com/alibb007/Simple-Meridian.git
cd Simple-Meridian

No git? Download the ZIP from GitHub and unzip it.

2. Start it

./start.sh

That's on a Mac. On Windows, double-click start.bat. Both build the app and open http://localhost:8501; the first build takes a few minutes.

3. Open the app

Go to http://localhost:8501, then press Take the 2-minute tour or upload your own weekly data.
